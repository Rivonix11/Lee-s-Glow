LEE'S GLOW CLEANING CO. — WEBSITE
===================================

Files:
- index.html
- css/style.css
- js/script.js
- assets/lees-glow-logo.png

How to preview:
1. Extract the ZIP.
2. Keep the folders together.
3. Open index.html in a browser, or use VS Code Live Server.

Built with:
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Bootstrap Icons
- Google Fonts

Notes:
- The logo supplied by the client is used in the navbar, hero and footer.
- The three customer reviews are included using the wording supplied in the screenshots.
- The quote form uses the Web3Forms access key already present in the supplied website files.
- Confirm that the Web3Forms account is configured to receive submissions at the intended email address before publishing.
- Bootstrap, icons and Google Fonts are loaded from CDNs, so an internet connection is needed for those assets.
